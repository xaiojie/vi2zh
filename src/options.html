浏览器兼容

  • Chrome / Edge：直接加载 dist/vi2zh-translator，Edge 在 edge://extensions 打开开发者模式即可。
  • Firefox：Firefox 109+ 支持 MV3，需在 about:debugging → “临时载入附加组件”选择 manifest.json；部分 chrome.* 回调需 polyfill，当前版本未做完整适配。
  • 更新：源码分发时用 npm run build 生成新版本，重新加载扩展后刷新页面即可。
